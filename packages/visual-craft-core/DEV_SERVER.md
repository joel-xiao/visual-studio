# Development Access

The development server for **visual-craft-core** is configured to run at:

- **Local Address**: [http://localhost:1430](http://localhost:1430)
- **Startup Command**: `npm run dev` (from the `packages/visual-craft-core` directory)

## Editor Modes
- **Design Mode**: Default view for building layouts.
- **Data Mode**: Switch via the top navigation bar to manage data sources and bindings.
- **AI Mode**: Use the AI assistant for chart generation and styling.
